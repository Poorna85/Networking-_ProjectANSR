# Networking Project – User Data Collection System

## Project Overview
This project demonstrates a basic networking and database integration system using:

- Linux Virtual Machine
- Apache Web Server
- PHP
- MySQL Database

The application allows users to:
- Enter personal information
- Upload files through a web interface
- Store data in a MySQL database
- Save uploaded files on the server

This project was implemented and tested in a virtualized networking environment using Oracle VirtualBox.

# Project Architecture

Client Browser
↓
Apache Web Server
↓
PHP Application
↓
MySQL Database

Uploaded files are stored in the server upload directory.

---

# Features

- User information form
- File upload functionality
- Database storage
- MySQL table integration
- Server-side file handling
- Networking through local IP address
- Linux command-line configuration

---

# Project Workflow

1. Configure Linux virtual servers
2. Enable Apache HTTP service
3. Connect PHP with MySQL
4. Create database and tables
5. Host PHP application
6. Access application through browser using IP address
7. Submit user details and upload files
8. Store uploaded files in server directory
